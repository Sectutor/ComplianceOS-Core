# ComplianceOS Plugin SDK

## Overview
Plugin SDK for the locked‑box, single‑tenant ComplianceOS with OpenClaw. Provides manifest schema, interfaces, JSON validators, and signing utilities for building tools, pipelines, scanners, slots, and playbooks.

## Quick Start
- Define a manifest with scopes, extension points, and JSON schemas.
- Implement ToolHandler or other interfaces.
- Validate responses as JSON objects and sign outbound requests.
